# PocketBall

Unity로 만든 2D 포켓볼(당구) 시뮬레이터. 외부 프로그램이 TCP로 접속해 큐를 칠 각도와 힘을 보내면, 시뮬레이터가 공을 굴리고 공이 모두 멈춘 뒤의 위치를 돌려줍니다.

## 실행

- Unity 6000.2.0f1
- `Assets/Scenes/MenuScene.unity`에서 시작합니다. 시작하면 TCP 서버가 포트 1447에서 접속을 기다립니다.
- 클라이언트가 핸드셰이크를 보내면 Start 버튼이 켜지고, 누르면 `PocketBallScene`으로 넘어갑니다.
- 클라이언트는 한 번에 하나만 받습니다.

## 프로토콜

메시지는 UTF-8 문자열이고 값은 `/`로 구분하며 끝에 `/`를 붙입니다.

| 방향 | 형식 | 의미 |
|---|---|---|
| 클라이언트 → 서버 | `9901/<닉네임>/` | 핸드셰이크 |
| 서버 → 클라이언트 | `9908/<순서>/0/0/.../` (값 12개) | 순서 신호. 1은 선공, 2는 후공 |
| 서버 → 클라이언트 | `x0/y0/x1/y1/.../x5/y5/` | 공 6개의 위치. 0번이 흰 공 |
| 클라이언트 → 서버 | `<각도>/<힘>/` | 흰 공 치기 |

- 각도는 도 단위이고, 0도가 +y 방향이며 시계 방향으로 늘어납니다.
- 힘은 내부에서 6배 해서 흰 공에 임펄스로 줍니다.
- 위치는 핸드셰이크 직후, 공이 놓인 직후, 그리고 친 공이 모두 멈춘 뒤에 보냅니다.

## 구성

| 스크립트 | 역할 |
|---|---|
| `TcpServer.cs` | TCP 서버, 핸드셰이크, 메시지 파싱과 상태 전송 |
| `BallManager2D.cs` | 공 배치, 치기, 위치 조회 |
| `PocketHole.cs` | 포켓에 들어간 공 처리. 흰 공은 시작 위치로, 나머지는 비활성화하고 다 들어가면 다시 배치 |
| `GameManager.cs` | 메뉴의 Start 버튼과 씬 전환 |
| `UnityMainThreadDispatcher.cs` | 수신 스레드의 작업을 메인 스레드로 넘김 |
| `DebugBallMotion.cs` | 생성될 때 공에 초기 속도를 주는 테스트 스크립트. 공 프리팹에 붙어 있음 |
